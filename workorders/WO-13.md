## Plan section (decisions, dated 2026-08-28)

- The prompt is the deliverable — no scripts, no tooling. opencode IS the
  installer runtime; the file ships in the repo it also installs.
- Interactive by design: the agent ASKS for hostname, Cloudflare token,
  and UI password (offer generation); confirms the full hostname before
  touching Cloudflare.
- Tunnel = three Cloudflare API calls with the exact shapes fleet's own
  proven Go code uses (create cfd_tunnel with config_src=cloudflare; PUT
  configurations ingress hostname→localhost:3000 + 404 catch-all;
  CNAME → <tunnel-id>.cfargotunnel.com with create/retarget/no-op
  idempotency), then `cloudflared service install <tunnel-token>` for
  boot persistence. Token transient (shell variable only) except the
  systemd unit cloudflared itself writes.
- Verification after every step with one-line evidence; hard success
  criteria: FLEET_INSTALL_OK line, corpus `fail=0`, check `pass=6 fail=0`,
  tunnel URL 2xx/3xx.
- Stop-and-report on anything un-covered; no mutating fleet commands in
  bootstrap (`init`/`onboard` come when the owner asks for a project).
