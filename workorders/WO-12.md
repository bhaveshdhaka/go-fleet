- Repo public — makes the WO-13 bootstrap prompt work token-free.
- bun is the package manager (openchamber's installer auto-detects and
  prefers it; upstream builds with oven/bun); Node 22 stays as the RUNTIME
  (upstream CLI is `#!/usr/bin/env node`; their runtime image installs
  nodejs). This corrects WO-11's npm-first guide — my error of omission.

  package only wraps the same binary).

  opencode server (4096); SSH TUI + iPad PWA are frontends to the same
  server + `~/.local/share/opencode`.
- Updates: Settings → About buttons / `openchamber update` (PM-aware);
  opencode updates offered in the UI with server restart. No scripts.
- Rules list cut to three incident-backed ones; single root identity per
  owner's flow.
