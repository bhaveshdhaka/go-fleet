## Plan section (decisions, dated 2026-08-28)

- **Component**: `fleet onboard arjun-hk --kind=service` registers the
  SDLC component (ops/PROJECTS.yaml + ci/pipelines/arjun-hk.yaml +
  ops/state/deployments.yaml entry); the registry entry gains
  `port: 8080`. Source lives at `apps/arjun-hk` (own pinned module,
  stdlib-only, mirroring fleetctl/fleethub).
- **Site**: single-page Go HTTP service. Embedded (embed.FS) dollarbucks
  menu page; `/healthz` for the k8s probe. Contract surface (asserted by
  C15a against the BINARY over loopback, not just the source):
  iOS — `viewport-fit=cover`, `apple-mobile-web-app-capable`,
  `apple-mobile-webapp-status-bar-style` (translucent), `theme-color`,
  `env(safe-area-inset-*)` padding; Safari — system font stack
  (no webfonts), `-webkit-font-smoothing: antialiased`; retina — all
  artwork inline SVG (vector, resolution-independent) plus a
  `min-device-pixel-ratio: 2` media query refinement. No JS, no external
  fetches, stdlib-only.
- **Gated promote**: built → dev → stage → prod with gates re-run at
  promote time (C3c; C4a; C6c) per lifecycle/gates.yaml. Dev approval:
  `FLEET_ACTOR=agent` (middle hop auto-approvable). Prod approval:
  `FLEET_ACTOR=owner-via-agent` — allowed by .fleet.yaml policy
  (allowed_actors: [owner, owner-via-agent]); the authority is the
  owner's directive that WO-10 ends with arjun.hk deployed, journaled
  verbatim next to the approval.
- **Ops deployment**: `ops register arjun-hk --host arjun.hk --port 8080
  --repo fleet/apps/arjun-hk` in the hk-03-dev site registry; image built
  by kaniko from the repo path (multi-stage golang:1.27-alpine →
  busybox:1.36 runtime, static binary); `ops deploy` self-reconciles
  CNAME arjun.hk → tunnel, tunnel ingress, gatus/dashboard monitoring;
  `ops verify` + content check + `ops doctor` all clear.
- **Rollback readiness** is inherited (WO-9 live drill proved
  build→deploy→rollback→verify on this same site machinery); WO-10
  records the fact rather than re-drilling.
- **STOP**: after the checklist every item carries evidence (journal
  lines, command outputs). No further mutation until the owner accepts.
