# WO-14 — Secrets divorce (no more sos-lab paths, ever)

> Owner directive 2026-08-28: "now there is no more sos lab, only go fleet."
> The migrated site still references `../sos-lab/secrets`; BOOTSTRAP.md
> tells the agent to keep the CF API token transient while the ops engine
> requires `cloudflare.env`. This workorder closes both.

## Decisions

- ONE mechanism: a site's secret env files live at
  `$FLEET_SECRETS_HOME/<site>/` when the env is set (hermetic seam for the
  corpus and containers), else `$HOME/.fleet/secrets/<site>/`. The
  `secrets_dir:` SITES.yaml override is DELETED — no more predecessor-tree
  references.
- Secret VALUES never enter git, the journal, logs, or chat. Key names and
  file counts may be journaled; paths inside $HOME are not.
- `site init --from` now COPIES the predecessor's `secrets/*.env` into the
  secrets home (0700 dir / 0600 files). The source tree is never mutated
  (WO-9 constraint preserved in spirit: source untouched, values relocated).
- BOOTSTRAP.md: the guided install STORES the CF API token at the end of
  Step 5 (`umask 077` + write to the secrets home), verified without
  printing. Token scope documented: Cloudflare Tunnel Edit + Zone DNS Edit.
